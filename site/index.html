它是什么

一份宪法 + 三个文件夹 + 一条日常循环

宪法

AGENTS.md
你是谁、什么值得记、什么绝对不记、AI 该怎么提醒你。

工作台

进行中.md
做到哪了、卡在哪、下一步是什么。

知识库

wiki/
一事一页，结论标来源，过时能追溯。

边界

private/
永不出本机。拿不准的先放这里。

它不是笔记软件，不是聊天机器人，也不是某个 App 的功能。它是一份可携带的文件，任何 AI 都能读。

起步

30 分钟，先让第一片转起来

  1. 0–5建一个空文件夹 my-brain
  2. 5–10填宪法里的 5 个空
  3. 10–15建 进行中.md、wiki/、private/
  4. 15–20把宪法发给你的 AI，让它读一遍
  5. 20–25说一件这周真实要做的事，让它用这个库帮你做
  6. 25–30让它把结论写进工作台，你确认

起步后：每天 5–10 分钟收尾；周末再花 20–30 分钟做一次周复盘。周复盘是额外的，不是替代日常。

三档

先选起步方式，不是选高低

初级

30 分钟起步

适合不碰终端、想先跑起来的人。

  • 工具：任何聊天 AI + 文件夹/Obsidian
  • 日常：每天 5–10 分钟
  • 周复盘：20–30 分钟（额外）
  • 得到：3 个文件夹 + “关于我” + 日常循环

中级

2–4 小时（一个下午）

适合会用 AI、敢上 Claude Code 的人。

  • 工具：Claude Code + vault
  • 日常：每天 5–10 分钟
  • 周复盘：20–30 分钟（额外）
  • 得到：AI 能读写的 vault + 收集/知识/反思

高级

1 天搭骨架

适合会终端和 git、想自动化的人。

  • 工具：Claude Code + git + 定时任务
  • 日常：每天 10 分钟
  • 周复盘：30 分钟（额外）
  • 得到：完整架构 + 记忆分层 + 自检器 + 调度

完整指南：初级 · 中级 · 高级 · 网页版新手上手包

Claude 说明：本文里的 Claude 指 Anthropic 的 Claude / Claude Code。初级不需要 Claude Code；中级用 Claude Code（命令行工具，能直接读写你的文件夹），需要敢用终端，不要求会编程；高级再加 git 和定时任务。如果你不用 Claude Code，也可以用其他能读写文件的 Agent 工具替代，本文以 Claude Code 为例。

差异化

为什么它不是又一个笔记软件

单位是决策，不是笔记

它围绕“你现在要做什么”，不是“你存了什么”。

不是聊天，是工作台

对话只是手段，任务推进才是目的。

不是黑箱，是可审计

它记了什么、为什么记、什么时候该忘，你都能看见。

随时调用

不是锁在某个对话里；任何 AI 都能读，问它就能带来源召回。

自我迭代

纠错、复盘、改宪法都会更新记忆；重要变更你确认。

不锁在任何一家 AI 里

一份文件，ChatGPT、Claude、Gemini 都能读。

不追求让你多用它

它的成功标准，是关掉它你还会想。

有边界

private/ 从第一天就存在，永不出本机。

笔记是仓库，外脑是循环：随时能叫出来，用完能改，改完会记住。

已有验证：社区 10+ 人已装机，已有社区外分享（结构化数据待补）。

FAQ

常见问题

要写代码吗？

不用。初级档零终端，任何聊天 AI + 一个文件夹就能开始。

能用 ChatGPT / Claude / Gemini 吗？

能。外脑是一份文件，不是某个 App 的功能；初级任何聊天 AI 都行，中高级用 Claude Code。

我的数据安全吗？

private/ 永不出本机；可分享层和私有层从第一天分开。

免费吗？

Starter Kit 开源；你的外脑是你自己的文件，不是租来的账号。

不用了会怎样？

文件还在你手里。没有锁定，没有迁移成本。

这不就是笔记软件吗？

不是。笔记软件是仓库，外脑是循环。

  • 随时调用：不是锁在某个对话里；只要 AI 能读这个文件夹，你随时可以问“我以前怎么处理过 X”，它带来源召回。
  • 自我迭代：每次纠错、每次复盘、每次改宪法，都会更新它的记忆和规则；但重要变更要你确认，不偷偷改。
  • 越用越像你：不是存得越多越好，而是记对了、用上了、改对了。

一句话：笔记存内容，外脑管“记什么、什么时候用、什么时候该忘”，而且随时能叫出来、用完能改、改完会记住。
