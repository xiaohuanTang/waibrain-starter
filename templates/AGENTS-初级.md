# 初级 · 30 分钟起步

> 完整指南：[docs/初级指南.md](../docs/初级指南.md)

1. 建空文件夹 `my-brain`。
2. 复制根目录 `AGENTS.md`，填 5 个空。
3. 建 `进行中.md`、`wiki/`、`private/`。
4. 把 `AGENTS.md` 发给任意聊天 AI（ChatGPT / Claude / Gemini / 豆包），让它读一遍。
5. 说一件这周真实要做的事，让它用这个库帮你做。
6. 让它把结论写进 `进行中.md` 或 `wiki/`，你确认。

- 工具：任何聊天 AI + 文件夹/Obsidian
- 不需要终端、不需要 git、不需要 Claude Code
- 起步后：每天 5–10 分钟；周末 20–30 分钟复盘（额外）
