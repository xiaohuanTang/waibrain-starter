# 中级 · 2–4 小时（一个下午）

> 完整指南：[docs/中级指南.md](../docs/中级指南.md)

- 工具：Claude Code + 一个 vault
- 需要：敢用终端；不要求会编程

步骤：

1. 安装 Claude Code。
2. 建 vault，复制 `AGENTS.md`。
3. 配置权限（见 `templates/隐私分层.md`）。
4. 让 Claude Code 读宪法，建 `进行中.md` / `wiki/` / `private/`。
5. 跑一件真实任务。
6. 让它把结论写进工作台，你确认。

起步后：每天 5–10 分钟；周末 20–30 分钟复盘（额外）。
