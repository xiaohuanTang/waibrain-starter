# 隐私分层

第一天就分两层：

| | share-ok | private |
| --- | --- | --- |
| 放什么 | 知识页、项目笔记、公开产出 | 钱、身体、家人、别人的信息；拿不准的 |
| git | 正常提交 | 永不 |
| 云备份 | 可以 | 本机 + 本地硬盘 |
| 给别的 AI 读 | 只读这层 | 不 |

## 动作

```bash
mkdir -p private/待定
printf "private/*\n!private/.gitkeep\n" >> .gitignore
```

口诀：拿不准的先放 `private/`。放宽随时可以，收回来收不干净。
