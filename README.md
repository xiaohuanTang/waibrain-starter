# 外脑 Starter Kit

> 你用过很多 AI，但关掉它，你还剩下多少？

外脑不是又一个第二大脑。它是一份你写给 AI 的宪法：该记的记，不该记的不记；该教你的时候，先问你。

30 分钟起步，让 AI 变成你的一部分，而不是你变成 AI 的一部分。

## 这是什么

- 一份宪法：`AGENTS.md`
- 一个工作台：`进行中.md`
- 一个知识库：`wiki/`
- 一道边界：`private/`
- 一条循环：对话 → 确认记忆 → 更新工作台 → 带来源召回 → 纠正 → 复盘

它不是笔记软件，不是聊天机器人，也不是某个 App 的功能。它是一份可携带的文件，任何 AI 都能读。

## 30 分钟起步（初级）

1. 建空文件夹 `my-brain`
2. 复制 `AGENTS.md`，填 5 个空
3. 建 `进行中.md`、`wiki/`、`private/`
4. 把宪法发给你的 AI，让它读一遍
5. 说一件这周真实要做的事，让它用这个库帮你做
6. 让它把结论写进工作台，你确认

起步后：每天 5–10 分钟收尾；周末再花 20–30 分钟做一次周复盘。周复盘是额外的，不是替代日常。

## 三档

| 档位 | 起步（一次性） | 日常 | 周复盘（额外） | 工具 |
| --- | --- | --- | --- | --- |
| 初级 | 30 分钟 | 每天 5–10 分钟 | 20–30 分钟 | 任何聊天 AI + 文件夹/Obsidian；零终端 |
| 中级 | 2–4 小时 | 每天 5–10 分钟 | 20–30 分钟 | Claude Code + vault；敢用终端 |
| 高级 | 1 天搭骨架 | 每天 10 分钟 | 30 分钟 | Claude Code + git + 定时任务；会终端/git |

## Claude 说明

本文里的 Claude 指 Anthropic 的 Claude / Claude Code。初级不需要 Claude Code；中级用 Claude Code（命令行工具，能直接读写你的文件夹），需要敢用终端，不要求会编程；高级再加 git 和定时任务。如果你不用 Claude Code，也可以用其他能读写文件的 Agent 工具替代，本文以 Claude Code 为例。

## 目录

```text
.
├── AGENTS.md              # 宪法模板
├── 进行中.md               # 工作台模板
├── wiki/                  # 知识库
├── private/               # 私有层（不进 git）
├── templates/             # 三档说明、学习模式、隐私分层
├── docs/                  # 五问选档、装机六步、FAQ、落地页文案
├── examples/              # 求职外脑、学习外脑
└── site/                  # 静态落地页
```

## 隐私

- `private/` 从第一天就存在，永不出本机。
- 拿不准的先放 `private/`；放宽永远比收紧容易。
- 示例和模板不含真实人名、公司名、联系方式。
