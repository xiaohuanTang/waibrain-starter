# 初级指南 · 30 分钟起步

日期：2026-11-15
背景与来源：基于爱玩社区《AI 原生新人类·装机包 v1》的初级路径改写。
结论：不碰终端、不写代码，用任意聊天 AI + 一个文件夹，30 分钟让第一片外脑转起来。

## 适合谁

- 你主要用手机，或电脑不常开。
- 你看到终端会发怵，不想学 git。
- 你想先跑起来，不想先读十篇文档。
- 你愿意每天花 5–10 分钟，用 AI 做一件真事。

## 你会得到

- 一个文件夹：`my-brain/`
- 一份宪法：`AGENTS.md`
- 一个工作台：`进行中.md`
- 一个知识库：`wiki/`
- 一道边界：`private/`
- 一条日常循环：对话 → 确认记忆 → 更新工作台 → 带来源召回 → 纠正 → 复盘

## 你需要

- 任意聊天 AI：ChatGPT / Claude / Gemini / 豆包，任选一个。
- 一个文件夹，或者 Obsidian（可选，不装也行）。
- 不需要终端、不需要 git、不需要 Claude Code。

## 30 分钟步骤

### 0–5 分钟：建库

- 在电脑或手机云盘里建一个空文件夹，命名 `my-brain`。
- 不要复制别人的库当底子；从空文件夹开始。

### 5–10 分钟：立宪法

- 复制仓库根目录的 `AGENTS.md` 到 `my-brain/AGENTS.md`。
- 填 5 个空：
  1. 称呼
  2. 现在最重要的一件事
  3. 1–3 个正在推进的项目
  4. 什么绝对不记
  5. 拿不准时怎么办
- 填不出来先写“待定”，不要编。

### 10–15 分钟：建三个位置

- 复制 `进行中.md` 到 `my-brain/进行中.md`。
- 建 `my-brain/wiki/`。
- 建 `my-brain/private/`。
- 如果你用 git，把 `private/` 写进 `.gitignore`；不用 git 也先建好这个文件夹。

### 15–20 分钟：让 AI 读宪法

- 打开你的聊天 AI，把 `AGENTS.md` 的内容发给它。
- 说：“这是我的外脑宪法。请读一遍，之后按它来。”
- 如果 AI 问你要不要记住什么，先让它说清楚“准备记什么”。

### 20–25 分钟：做一件真事

- 说一件你这周真实要做的事，不是演示题。
- 例：帮我整理明天面试的三个问题；帮我把这段项目经历写成 STAR。
- 让它从 `wiki/` 或 `进行中.md` 里找旧内容；如果没有，就让它先帮你做。
- 你要亲眼看到一次：“它居然知道我的事。”

### 25–30 分钟：留一条痕

- 让它把结论写进 `进行中.md` 或 `wiki/`。
- 你确认：这条值得记吗？记对了吗？
- 如果它记错了，当场纠正；这就是“判断记录”的起点。

## 第一周怎么用

- 每天 5–10 分钟，只做一件事：用外脑推进一个真实任务。
- 每次结束前，让它更新 `进行中.md`。
- 不急着自动化；先看它取得准不准。
- 周末花 20–30 分钟做一次周复盘：这周记了什么、用了什么、下周改什么。

## 第一月怎么用

- 每周加一个内化习惯（见 `docs/新手上手包.md`）。
- 每周复查一次 `private/待定/`。
- 如果一条规则让你烦，回去改宪法；不要忍着。

## 验收：三个信号

1. 它能带来源召回旧内容。
2. 它会把结论写进工作台。
3. 它会在拿不准时先问你。

三个都出现，说明外脑开始转了。

## 常见错误

- **复制别人的库当底子**：个人信息混入。
- **宪法填得太满**：用不起来；先填 5 个空。
- **一上来就自动化**：取用没跑顺，先存一堆垃圾。
- **把它当笔记软件**：只存不用，等于没装。
- **关掉学习模式**：产出更快，但人更空。
