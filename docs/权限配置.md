# 权限配置

日期：2026-11-15
背景与来源：基于爱玩社区《AI 原生新人类·装机包 v1》的权限配置页改写。
结论：自动化的前提不是“把门全拆了”，而是给 AI 划一块自留地：库内随便写，危险动作永远问。

## 症状

让 AI 定时沉淀、自动整理，它却每一步都弹“是否允许？”——你不在，它就一直等。任务其实从来没自动跑成过。

## 原理

AI 工具出厂默认：每次写文件、跑命令都要人点头。这是对的，保护新手。

要自动化，不是关掉所有确认，而是：
- **库目录内**：允许读写。
- **危险动作**：删除、推上网、发消息、库外写、读凭证——永远要问。

## Claude Code 配置

在库目录里新建 `.claude/settings.json`（只对这个库生效）：

```json
{
  "permissions": {
    "allow": [
      "Read",
      "Edit(./**)",
      "Write(./**)",
      "Bash(git add:*)",
      "Bash(git commit:*)",
      "Bash(git status:*)",
      "Bash(git log:*)",
      "Bash(python3:*)"
    ],
    "deny": [
      "Read(./private/**)",
      "Edit(./private/**)"
    ],
    "ask": [
      "Bash(rm:*)",
      "Bash(git push:*)"
    ]
  }
}
```

人话翻译：库里随便读写、git 记账随便做、python 脚本随便跑；`private/` 连读都不许；删东西、推上网，永远回来问我。

模板见 `templates/settings.json`。

## 桌面版的两个坑

1. 设置里选的默认权限模式**可能不生效**（已知 bug）。当前实际有效的做法：每个会话开始时，在权限选择里手动选一次放行模式。
2. 桌面版和命令行版的设置**不完全互通**。用哪个面就在哪个面验证。

## Codex / 其他工具

配置面不同，不要照抄。原则一样：库内放行，删除/出网/库外写永远问。对照实机验证后再写进你的宪法。

## 定时任务

自动任务没有人在旁边点允许，所以：
1. 先用上面的 settings 白名单把权限配好，**手动跑通一次**。
2. 再挂定时（macOS 用 launchd / crontab）。
3. 定时命令里不要用“全部放行”开关；白名单没覆盖到的动作，宁可让任务失败留日志，也不要静默放行。

## 配完当场验证（两步，一分钟）

1. 让 AI：“在库里建一个 `test.md`，写一行字。” → 应该**不弹确认**，文件出现。
2. 让 AI：“删掉 `test.md`。” → 应该**弹确认**。

第 1 步过 = 自留地生效；第 2 步过 = 红线还在。只过第 1 步不过第 2 步 = 放太开，回去补 `ask` / `deny`。

## 永远要确认的红线

- 删除类：`rm`、清空目录、覆盖不是它建的文件
- 出网类：发消息、发邮件、发帖、任何“把内容送出库”的动作
- 库外写：家目录、系统目录、别的项目
- 凭证类：任何含密码/密钥的文件，读都不该读
