# 学习模式

日期：2026-11-15
背景与来源：基于爱玩社区《AI 原生新人类·装机包 v1》的护栏配置改写；PNAS 2025 实验数据转引自原装机包。
结论：默认先开学习模式；该教你的时候，AI 先反问、给线索，不直接甩答案。

## 两个模式，一句话区别

| | 学习模式 | 干活模式 |
| --- | --- | --- |
| 什么时候用 | 你想**学会**一个东西 | 你要**产出**一个东西（赶时间的真实活儿） |
| AI 怎么做 | 先反问、给线索，逼你自己想；答案要你先交尝试才给 | 正常助手，答案照给 |
| 目的 | 本事长进你脑子 | 把活干完 |

**默认纪律**：装完头两周学习模式全开；之后钥匙交给你，但凡是“学习”性质的场景，默认保持学习模式。

## 学习模式提示词

把下面这段发给 AI：

```text
从现在起进入「学习模式」。当我问你问题时：
1. 先不要直接给答案。先问我“你自己的想法/思路是什么，先写一步看看”。
2. 等我给出尝试后，再给方向和线索，一次只给一步，不要一口气给全。
3. 只有我明确说“给我答案”时，才给完整答案；给之前先问我“你自己先试到哪了”。
4. 我答错时，不要直接纠正结论，先反问引导我自己发现错在哪。
目的：帮我自己想明白、把本事长在我身上，而不是替我想。
```

## 家长版（孩子用 AI 时）

把下面这段发给孩子的 AI：

```text
这是一个孩子在学习。请你只提问、只给提示、只给线索，
永远不要直接给出答案，也不要替他写完；
用鼓励的语气，引导他自己一步一步想出来。
如果他想直接要答案，就先请他说说自己已经想到哪儿了。
```

## 怎么固定下来（三选一）

- **最简单**：每次开“学习”对话，手动粘贴提示词。
- **中等**：把提示词存成便签/文本片段，一键粘贴。
- **进阶**：写进库里的项目配置或宪法，让它在特定目录/项目里常驻生效。

## 一句话验收

配好后，在学习模式里问它一个你会的问题——**它应该先反问你“你怎么想”，而不是直接甩答案。** 一上来就给答案，就是没生效，回去重贴提示词。

## 为什么非有它不可

一个近千人的真实实验（PNAS 2025）发现：能随便用 AI 的人，练习时成绩高 48%，**一撤掉 AI 考试反而比没用 AI 的低 17%**；只有“只给提示、不给答案”的护栏版才没这个伤害。

**用得爽 ≠ 学到了，可能正被掏空。护栏就是那道闸。**

## 干活模式

需要 AI 正常干活时，直接说：

```text
进入「干活模式」：这是真实产出，请正常、高效地给我完整结果。
```
