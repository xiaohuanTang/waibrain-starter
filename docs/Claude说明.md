# Claude 说明

本文里的 Claude 指 Anthropic 的 Claude / Claude Code。

- **初级**：不需要 Claude Code。任何聊天 AI（ChatGPT / Claude / Gemini / 豆包）+ 文件夹/Obsidian 即可。
- **中级**：用 Claude Code（命令行工具，能直接读写你的文件夹）。需要敢用终端，不要求会编程。
- **高级**：Claude Code + git + 定时任务。需要会终端和 git。

如果你不用 Claude Code，也可以用其他能读写文件的 Agent 工具替代；本文以 Claude Code 为例。
