# 5 问选档 · 1 页 PRD（示例）

日期：2026-11-15
背景与来源：外脑 Starter Kit 的 onboarding 功能；本文是给初学者看的 1 页 PRD 示例。
结论：用 5 个问题在 2 分钟内给出档位和下一步，降低首次启动摩擦。

## 1. 用户

想搭外脑但不知道从哪开始的人（初级 / 中级 / 高级）。

## 2. 问题

- 不知道适合哪一档。
- 怕选太难，装不起来；也怕选太浅，不够用。
- 不知道下一步该做什么。

## 3. 目标 / 非目标

**目标**：2 分钟内给出档位 + 推荐路径 + 下一步 CTA。  
**非目标**：不做账号、不做长问卷、不做复杂测评。

## 4. 用户流程

落地页 → 5 问 → 结果页 → 生成 `AGENTS.md` / 看模板。

## 5. 功能需求（P0 / P1 / P2）

- **P0**：5 道 A/B/C 题、进度、结果、CTA。
- **P1**：跳过选档、历史结果、分享。
- **P2**：基于结果推荐领域包。

## 6. 指标

- 选档完成率 ≥ 60%
- 宪法生成率 ≥ 50%
- 模板点击率 ≥ 30%

## 7. 风险

- 问题太多 → 5 题上限。
- 结果不准 → 给出“为什么”和“可改档”。
- 用户不想答 → 可跳过，先看三档。

## 8. 开放问题

- 结果页要不要给推荐理由？
- 要不要保存进度？
- 要不要显示完成人数？（没有真实数据就不显示）
