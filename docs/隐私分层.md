# 隐私分层

日期：2026-11-15
背景与来源：基于爱玩社区《AI 原生新人类·装机包 v1》的隐私分层模板改写；「分层镜像」原则原始出处为张赟（2026-07-28）。
结论：库从第一天就分 share-ok / private；上云、接机器人、给别的 AI 读的，永远只是 share-ok 的镜像。

## 两层怎么分

| | share-ok（可分享层） | private（私有层） |
| --- | --- | --- |
| 放什么 | 知识页、项目笔记、流程模板、公开产出 | 涉及钱、身体、家人、**别人**的一切；拿不准的 |
| 在哪 | 库里除 `private/` 外的所有目录 | `private/` 目录 |
| git 同步 | 正常提交 | 永不（靠 `.gitignore` 兜底） |
| 云备份 / 网盘 | 可以 | 本机 + 本地硬盘备份 |
| 接飞书 / 微信机器人 | 只读这一层 | 不 |
| 给第二个 AI 读 | 只读这一层 | 不 |

口诀：**拿不准的先放 `private/`。放宽随时可以，收回来收不干净。**

## 装机动作（两分钟）

```bash
mkdir -p private/待定
printf "private/*\n!private/.gitkeep\n" >> .gitignore
```

然后在外脑宪法的红线区确认已有这条：**`private/` 的内容永不进入云同步、群聊、其他 AI 的上下文。**

## 装机前的清洗清单（给安装者）

帮别人装机，只允许携带本 Starter Kit 的模板文件。动手前自查：

- [ ] 我没有复制我自己库里的任何文件当“参考底子”
- [ ] 我给的示例里没有真实人名（包括我自己的）、真实公司名、真实数字
- [ ] 聊天记录、截图、“我之前是这么配的”笔记——都没有进对方的库
- [ ] 模板里的 `〔 〕` 全部是**对方**填的，不是我顺手填的
- [ ] 装完我检查了一遍：`grep -r "我的名字" 对方库/` 应该零命中

> 为什么这么严：真实案例——安装者拿群里几个版本的资料拼着装，把两位老师的名字永久写进了朋友的外脑。对方还没感受到价值，先多了一层信任负担。

## 每周一分钟：private/待定 复查

宪法 Q3 选了“先记待定”的，每周挑一个固定时间把 `private/待定/` 过一遍：

- 该升 share-ok 的移出去
- 该留的留下
- 没用的删掉

让“拿不准”有出口，分层才守得住。

## 常见错误

- **先建库、后分层**：收拾永远赶不上扩散。
- **把 private 放进云盘**：同步一次，就等于公开一次。
- **给第二个 AI 读整个库**：只给它 share-ok 的镜像。
- **拿不准就默认 share-ok**：默认应该是 private。
