# 五问选档

每问选 A/B/C：

1. **设备**：A 只有手机 / B 有电脑但不常开 / C 电脑是主力
2. **终端**：A 发怵 / B 敢试 / C 日常
3. **AI 深度**：A 偶尔聊天 / B 常用 / C 用过 Agent 读写文件
4. **折腾意愿**：A 想找人帮 / B 愿意排查半小时 / C 享受自动化
5. **时间**：A 每周不到 1 小时 / B 每周 1–3 小时 / C 每周 3 小时以上

判档：Q1=A → **初级**；否则 C≥3 且 Q2=C → **高级**；否则 B+C≥3 → **中级**；不足 → **初级**。

## 结果页

- 初级：30 分钟起步；零终端；任何聊天 AI + 文件夹/Obsidian。
- 中级：2–4 小时；Claude Code + vault；敢用终端。
- 高级：1 天搭骨架；Claude Code + git + 定时任务；会终端/git。
