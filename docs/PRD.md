# 一、PRD

## 1. 背景与问题

“第二大脑”产品很多，但大多数人装不起来：

- 教程太长，看完不知道从哪一步开始。
- 模板太满，填完就累，第二天不用了。
- 装完像笔记软件，AI 还是不知道怎么帮你。
- 不知道怎么判断“装没装成”。

外脑 Starter Kit 要解决的不是“再做一个笔记软件”，而是：**让一个非技术用户，在 30 分钟内拥有一个能用的 AI 外脑，并且知道下一步怎么用。**

### 验证现状（2026-11-15）

- **装机与留存**：社区内 **10+ 人已装机，超过 7 天仍在使用**。
- **5 人两周实况复盘（2026-09-02）**：社区成员各自晒两周真实用法。核心共识是：**“模型是市面上的好马，外脑是每个人量身定制的马具（harness）；分水岭是有没有把日常工作搬进去形成闭环。”**
- **正向信号**：
  - 每天 11 点自动沉淀跑通；讲座规范自动沉淀、比赛资格判断等场景出现正反馈。
  - 所有文件一个入口进外脑；把外脑文件夹丢进 Obsidian，能长出密集关联图，被视为“搭建成功”的检验。
  - 时间/日记/冥想/工作全量入脑，拿到“准得可怕”的个人诊断报告。
  - 工作台（围绕业务/项目/任务，不围绕对话）+ 模型调度 + 运维自愈 + ingest 管道（高级用户）。
- **负向信号**：
  - **“用 AI 更累”**：有成员停用 5 天，靠手写复盘找回内化。
  - **“装了但用法没变”**：工具装上了，工作方式还是原来的。
  - **“优质信源没接进外脑”**：缺一手信源/ingest。
- **社区给出的解法**：探索日/产出日分开；每 1–2 周手写复盘再让 AI 结构化；AI 进新阶段先讲概念；把低价值耗时的事交给外脑，用 AI 做带来能量的事。
- **对外推广洞察**：认知分三层——豆包层 → AI 原生平台层 → 外脑层；不能跨层硬讲，要先帮对方找到 aha moment。
- **结论**：“装得起来”已验证；“装完还用”有 7 天留存信号；“用完变强”仍待验证。
- 来源：主人提供的社区 2026-09-02 会议纪要；姓名与内部合作信息已省略；非对照实验，样本 5 人。

## 2. 目标用户

| 用户 | 特征 | 他要什么 | 他怕什么 |
| --- | --- | --- | --- |
| 初级 · 零终端 | 主要用手机/电脑不常开；看到终端发怵 | 今天就能跑起来的最小闭环 | 教程太长、装完没用 |
| 中级 · 敢用工具 | 常用 AI，敢上 Claude Code | AI 能直接读写文件、少复制粘贴 | 权限配不好、隐私泄露 |
| 高级 · 自动化 | 会终端/git，想自动化 | 事件流、自检、定时任务 | 过度工程、维护成本 |

**首发重点：初级。** 因为“所有人”的入口不是高级，是零终端。

## 3. 目标与非目标

**目标**

- 让用户在 30 分钟内完成第一版外脑（宪法 + 工作台 + `wiki/` + `private/`）。
- 让用户在第一次使用中看到“它居然知道我的事”。
- 让用户知道下一步该做什么（7 天循环、五个习惯）。
- 让用户愿意把模板推荐给同类人。

**非目标**

- 不做笔记编辑器的完整功能。
- 不做云同步、登录、多用户。
- 不做 AI 对话产品本身；外脑是“给任何 AI 用的文件”。
- 不做自动抓取/自动写入；先保证用户确认。

## 4. 价值主张

> 不是又一个第二大脑。是一份你写给 AI 的宪法：该记的记，不该记的不记；该教你的时候，先问你。
> 30 分钟起步，让 AI 变成你的一部分，而不是你变成 AI 的一部分。

## 5. 用户旅程

1. 从 GitHub / 朋友分享 / 搜索进入落地页。
2. 看 30 秒价值主张，点「2 分钟选档」。
3. 回答 5 个问题，得到档位和推荐路径。
4. 点「生成我的 `AGENTS.md`」，填 5 个空，实时预览。
5. 复制/下载宪法，或点「Use this template」创建仓库。
6. 按 30 分钟清单走完 6 步。
7. 完成第一件真事，看到“它知道我的事”。
8. 7 天后回来：看清单、周复盘、改一条规则。

## 6. 功能需求

### P0 · MVP 必须有

| 编号 | 功能 | 说明 |
| --- | --- | --- |
| F1 | 落地页 | 30 秒价值主张、三个卖点、三档入口、FAQ |
| F2 | 5 问选档 | A/B/C 选项，进度 1/5，可跳过 |
| F3 | 结果页 | 档位、时间、工具、推荐路径、下一步 CTA |
| F4 | `AGENTS.md` 生成器 | 5 个输入 → 实时预览 → 复制/下载 |
| F5 | 30 分钟清单 | 6 步，可勾选，进度条 |
| F6 | 模板交接 | GitHub template / 下载 zip / 新手上手包 |

### P1 · 下一步

- 7 天回访提醒（邮件/日历，可选）。
- 3 个领域示例：求职、学习、项目。
- 一键复制学习模式/干活模式提示词。
- 移动端优化。

### P2 · 以后

- GitHub OAuth 一键创建“我的外脑”仓库。
- LLM onboarding 助手（只做引导，不替用户填）。
- 领域包市场。
- 匿名激活数据看板。

## 7. 关键设计决策

- **先选档，再生成**：用户先知道自己适合哪一档，再填宪法；不要一上来给一张大表。
- **5 个空，不是 50 个**：宪法可以很长，但第一次只填 5 个空。
- **本地生成**：`AGENTS.md` 在浏览器本地生成，不上传；隐私是产品的一部分。
- **可跳过**：高级用户可以直接看模板；不要强迫所有人做 quiz。
- **没有账号**：先让用户拿到文件；账号是以后的事。

## 8. 指标

**北极星指标**：完成 30 分钟清单并做成一件真事的用户数。

| 指标 | 定义 | 目标 | 已有信号 |
| --- | --- | --- | --- |
| 装机人数 | 已装机用户 | ≥ 10 | 社区 10+ 人 |
| 7 天留存 | 装机后 7 天仍在用 | ≥ 50% | 10+ 人 >7 天（定性） |
| 定性反馈 | 5 人两周实况复盘 | 有正/负向信号 | 已完成（2026-09-02） |
| 选档完成率 | 完成 5 问 / 进入 quiz | ≥ 60% | 待补 |
| 宪法生成率 | 生成 `AGENTS.md` / 完成选档 | ≥ 50% | 待补 |
| 模板点击率 | 点 Use this template 或下载 / 生成宪法 | ≥ 30% | 待补 |
| 清单完成率 | 勾完 6 步 / 开始清单 | ≥ 40% | 待补 |
| 首次 aha 时间 | 从进入到“它知道我的事” | ≤ 30 分钟 | 待补 |
| 第一个闭环 | 至少完成一个真实闭环 | ≥ 50% | 待补 |
| 推荐意愿 | 社区装机用户中愿意推荐 | ≥ 2/3 | 待补 |

> 已有 10+ 人装机，说明“装得起来”初步成立；“装完还用”仍待验证。样本不大，不宣称统计显著。

## 9. 风险与对策

| 风险 | 对策 |
| --- | --- |
| “又一个第二大脑” | 首屏明确“不是笔记软件”；用“宪法 + 循环”做差异 |
| 教程太长 | 首屏只放 30 秒 + 30 分钟；完整文档放 `docs/` |
| 填宪法太累 | 只填 5 个空；其余“待定”，随时改 |
| 隐私担忧 | 本地生成，不上传；`private/` 第一天就有 |
| 装完不用 | 30 分钟清单 + 7 天循环 + 五个习惯 |
| 用 AI 更累 | 探索日/产出日分开；每 1–2 周手写复盘；学习模式先反问 |
| 装了但用法没变 | 第一个闭环：先把重复度最高的一件事搬进外脑 |
| 优质信源没接进 | ingest 管道 + 信源清单；先接 3–5 个一手信源 |
| 高级用户觉得浅 | 可跳过 quiz，直接看高级指南/模板 |

> 已有 10+ 人装机，说明“装得起来”的风险初步降低；“装完还用”仍需验证。

## 10. Roadmap

- **v0.1（已有）**：落地页、onboarding 页面、模板仓库、完整文档；社区 10+ 人装机，超过 7 天仍在使用；5 人两周实况复盘。
- **v0.2（下一步）**：5 问选档 + 生成 `AGENTS.md` + 30 分钟清单 + “第一个闭环”模板；同时补 10+ 装机用户的结构化反馈。
- **v0.3**：5 位老用户回访 + 外脑体检 v0 + 搭建 MD/信源清单（社区资产），改文案/流程。
- **v0.4**：领域示例（求职/学习/项目）+ ingest 信源清单。
- **v1.0**：一键创建 GitHub 仓库（需后端/OAuth）。

## 11. 开放问题

- 选档结果要不要给“推荐理由”，还是只给档位？
- 生成器要不要允许用户直接编辑 Markdown，还是只填表单？
- 30 分钟清单要不要做成可保存进度（localStorage）？
- 7 天回访用邮件、日历，还是站内提醒？
- 要不要显示“已有多少人完成”？没有真实数据就不显示。
- 10+ 装机用户里，有多少完成 30 分钟清单？有多少完成了“第一个闭环”？
- “用 AI 更累”在多少人身上出现？学习模式有没有缓解？
- 优质信源没接进：最常见的 3 个信源是什么？
- 社区外用户是怎么找到的？他们和社区内用户有什么不同？
- 有没有可以匿名引用的反馈原话？

# 二、原型

## Screen 1 · 落地页

**目标**：30 秒讲清楚“这是什么、为什么不是笔记软件、下一步做什么”。

**结构**

1. 顶部导航：为什么 / 怎么做 / 三档 / 新手上手包 / FAQ / GitHub
2. Hero：
   - H1：你用过很多 AI，但关掉它，你还剩下多少？
   - 副标题：外脑不是又一个第二大脑。它是一份你写给 AI 的宪法……
   - 主 CTA：2 分钟，测你适合哪一档
   - 次 CTA：Use this template
   - 微文案：不用写代码 · 任何 AI 都能用 · `private/` 永不出本机
3. 问题：聊完就忘 / 记了不用 / 越用越依赖
4. 它是什么：宪法 + 工作台 + 知识库 + 边界
5. 30 分钟清单
6. 三档
7. 差异化 + FAQ
8. 底部 CTA

**交互**：主 CTA 进入 Screen 2；次 CTA 新窗口打开 GitHub。

## Screen 2 · 5 问选档

**目标**：2 分钟内给出档位，不让人填长表单。

**结构**

- 进度：`1 / 5`
- 问题：你日常主力设备是？
- 选项卡片：
  - A 只有手机
  - B 有电脑但不常开
  - C 电脑是主力工作台
- 底部：上一题 / 下一题 / 跳过，先看三档

**交互**

- 选 A/B/C 后自动进入下一题，或点“下一题”。
- 最后一题后进入 Screen 3。
- 跳过 → 直接到 Screen 3 的“三档对照”版本。

## Screen 3 · 结果页

**目标**：告诉用户“你适合哪一档、为什么、下一步做什么”。

**结构**

- 标题：你适合：**初级 · 30 分钟起步**
- 推荐理由：你主要用手机/不常开电脑，先从零终端路径开始。
- 三个数字：
  - 起步：30 分钟
  - 日常：每天 5–10 分钟
  - 周复盘：20–30 分钟（额外）
- 工具：任何聊天 AI + 文件夹/Obsidian
- 下一步按钮：
  - 主：生成我的 `AGENTS.md`
  - 次：先看模板
- 底部：其他档位对照（初级/中级/高级）

**交互**：主按钮进入 Screen 4；次按钮到 GitHub。

## Screen 4 · `AGENTS.md` 生成器

**目标**：让用户在 3 分钟内拿到一份“自己的”宪法。

**结构**

左侧表单：

1. 称呼：〔必填〕
2. 现在最重要的一件事：〔必填〕
3. 正在推进的 1–3 个项目：〔可空〕
4. 什么绝对不记：〔默认四条，可加〕
5. 拿不准时怎么办：〔先问 / 待定 / 不记〕

右侧实时预览：

```md
# 外脑宪法 · [称呼]

## 我是谁的外脑
- 主人：[称呼]
- 现在最重要的事：[一句话]
- 正在推进：1) [项目] — [目标/卡点]
- 我的角色：记忆系统和参谋……

## 沉淀规则
Q1 什么值得记：……
Q2 什么绝对不记：……
Q3 拿不准：……
```

底部：

- 复制 Markdown
- 下载 `AGENTS.md`
- Use this template
- 隐私提示：全部在浏览器本地生成，不上传。

**交互**

- 输入即时更新预览。
- 空字段显示“待定”，并提示“之后可以改”。
- 复制/下载成功后 toast。
- 草稿存 localStorage，刷新不丢。

## Screen 5 · 30 分钟清单

**目标**：让用户知道现在做哪一步、还剩几步。

**结构**

- 标题：30 分钟，先让第一片转起来
- 进度条：0 / 6
- 6 步卡片：
  1. 建空文件夹 `my-brain`
  2. 复制 `AGENTS.md`，填 5 个空
  3. 建 `进行中.md`、`wiki/`、`private/`
  4. 把宪法发给你的 AI
  5. 说一件真实要做的事
  6. 让它把结论写进工作台
- 每步：勾选框 + 预计时间 + “遇到问题？看 docs”
- 底部：完成后 → “读新手上手包”

**交互**：勾选保存到 localStorage；全勾完显示“第一片转起来了”。

## Screen 6 · 交接页

**目标**：把用户送到模板/文档，不让他在页面里迷路。

**结构**

- 标题：拿走你的外脑
- 三个按钮：
  - Use this template（GitHub）
  - 下载 zip
  - 读新手上手包（`onboarding.html`）
- 小字：不用 GitHub 也能用；下载后解压即可。

## Screen 7 · 新手上手包（已有）

**目标**：头两周怎么用、五个习惯、提示词卡。

**结构**：装起来 → 头两周 → 五个小习惯 → 两张提示词卡 → 成功标准。  
**交互**：复制提示词、打印/存 PDF。

## 边界情况

- **不知道填什么**：允许“待定”；提示“先写一个，之后改”。
- **高级用户**：跳过 quiz；直接看高级指南/模板。
- **手机用户**：选项卡片纵向排列；生成器预览折叠；复制按钮优先。
- **没有 GitHub**：下载 zip；不需要终端。
- **隐私担忧**：明确“本地生成、不上传”；不显示任何账号/登录。
- **中途离开**：localStorage 保存 quiz/清单进度。

## 视觉与交互

- 风格：暖纸色背景、衬线标题、蓝色强调；像一本手册，不像 SaaS 后台。
- 组件：卡片、步骤条、进度条、代码块、复制按钮。
- 反模式：不做注册墙、不做弹窗、不做“限时优惠”、不自动播放。
- 可访问性：键盘可操作、对比度足够、按钮有文字标签。

## 技术实现（MVP）

- 静态 HTML/CSS/JS，无后端。
- 选档逻辑在 JS；结果映射到三档。
- `AGENTS.md` 用模板字符串生成；localStorage 存草稿。
- 部署 GitHub Pages；模板仓库用 “Use this template”。
- 分析：只记匿名事件（quiz_start / quiz_complete / generate / template_click），不记表单内容；也可以先不接分析。
