# 装机总说明

日期：2026-11-15
背景与来源：本 Starter Kit 基于爱玩社区《AI 原生新人类·装机包 v1》的方法论改写；本文是产品化版本。
结论：先装最小闭环（宪法 + 工作台 + 知识库 + 私有层），头两周先取后存，不要一上来就自动化。

## 这个包有什么

| 文件 | 作用 |
| --- | --- |
| `AGENTS.md` | 新库的第一个文件：它是谁、记什么、不记什么、怎么提醒你 |
| `进行中.md` | 工作台：做到哪了、卡在哪、下一步是什么 |
| `wiki/` | 沉淀的知识，一事一页 |
| `private/` | 永不出本机 |
| `templates/学习模式.md` | 让 AI 在你学习时先别给答案 |
| `templates/隐私分层.md` | 第一天就分层 |
| `docs/权限配置.md` + `templates/settings.json` | 让 AI 能干活、但删东西要问你 |
| `tools/deposit_report.py` | 沉淀日报：每天让“外脑记了什么”见光 |

## 装机六步（约 30–40 分钟）

1. **建库**
   新建空文件夹，例如 `~/my-brain`。
   初级可以跳过 git；中高级需要版本管理时再 `git init`。
   ⚠️ 从空文件夹开始，不要复制现成库当底子——那正是个人信息混入的路径。

2. **立宪法**
   打开 `AGENTS.md`，和主人一起把 `〔 〕` 填完。
   特别是“什么绝对不记”和“拿不准怎么办”，必须由主人亲口回答。
   填不出来先写“待定”，不要编。

3. **分隐私**
   按 `templates/隐私分层.md` 建 `private/`，写进 `.gitignore`。
   口诀：拿不准的先放 `private/`；放宽永远比收紧容易。

4. **配权限**
   按 `docs/权限配置.md` 做一遍；配置模板见 `templates/settings.json`。
   当场验证：让 AI 在库里建文件应不弹确认；删文件应弹确认。两个都对才算好。

5. **配护栏**
   按 `templates/学习模式.md`，把学习模式提示词发给 AI。
   当场验证：在学习模式里问一个你会的问题，它应该先反问你“你怎么想”，而不是直接给答案。

6. **点火 · 先取后存**
   让主人说一件他这周真实要做的事（不是演示题），AI 用这个库帮他做成。
   让主人亲眼看到“它居然知道我的事”——这是第一小时必须出现的 aha。
   头两周先不开全自动沉淀：先把“取和用”跑顺，尝到甜头再开“存”。

## 四条设计原则 + 内化优先

1. **零携带**：包里没有任何具体人名、案例、历史数据，只有占位符。
2. **规则共建**：沉淀标准由主人第一天亲手填，写明“随时可改”。
3. **分层镜像**：从第一天分 share-ok / private；上云、接机器人、给别的 AI 读的，永远只是 share-ok。
4. **沉淀见光**：每天一份日报回答“记了什么”；不满意就去改宪法。
5. **内化优先**：装的不仅是 AI 那一半，还有主人那一半的习惯。护栏默认开，内化纪律写进宪法。

## 谁能教别人装

自己没真正跑通过外脑（至少 2 次用它做成真事）的人，不建议给别人装机、讲外脑课。

原因：没跑通的人去教，自己心里都在打鼓；失败会反噬信心。

## 装完之后

把 `docs/新手上手包.md` 交给主人自己走：头两周就练一件事 + 五个小习惯。

别贪多：一周一个动作，顺序反了就会“觉得乱”。

## 常见错误

- **复制别人的库当底子**：个人信息混入，信任先欠一笔。
- **一上来就自动化**：取用没跑顺，先存一堆垃圾。
- **宪法填得太满**：用不起来；先填 5 个空，跑两周再补。
- **关掉学习模式**：产出更快，但人更空；默认保持学习模式。
- **把所有东西都当“知识”**：工作台、判断记录、复盘也是外脑的一部分。
