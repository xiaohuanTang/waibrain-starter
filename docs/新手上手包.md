# 新手上手包

日期：2026-11-15
背景与来源：基于爱玩社区《AI 原生新人类·装机包 v1》配套的《新手上手包》改写。
结论：头两周只练一件事——用外脑做成一件真事；五个小习惯一周加一个，别贪多。

> 网页版（可打印/存 PDF）：https://xiaohuantang.github.io/waibrain-starter/onboarding.html

## 第一部分：装起来（约 30 分钟）

1. 建一个空文件夹 `my-brain`。
2. 复制 `AGENTS.md`，填 5 个空：称呼、最重要的事、1–3 个项目、什么不记、拿不准怎么办。
3. 建 `进行中.md`、`wiki/`、`private/`。
4. 把宪法发给你的 AI，让它读一遍。
5. 说一件这周真实要做的事，让它用这个库帮你做。
6. 让它把结论写进 `进行中.md` 或 `wiki/`，你确认。

装完之后，先别急着自动化。头两周只做一件事：**先取后存**。

## 第二部分：头两周怎么用

### 第 1 周：让它先懂你

- 每天花 5–10 分钟，说一件真实的事。
- 让它从 `wiki/` 或 `进行中.md` 里找相关旧内容。
- 你要亲眼看到一次：“它居然知道我的事。”
- 不要急着让它自动沉淀；先看它取用准不准。

### 第 2 周：开始留痕

- 每次做完一件事，让它写一句结论到 `wiki/` 或 `进行中.md`。
- 你确认：这条值得记吗？记对了吗？
- 如果它记错了，当场纠正；这就是“判断记录”的起点。
- 周末花 20–30 分钟做一次周复盘：这周记了什么、用了什么、下周改什么。

## 第三部分：五个小习惯（关键中的关键）

一周只加一个，顺序别乱：

1. **先自己想，再问它**：开 AI 前先写三行自己的想法/预判，再看它怎么说，然后记“我哪里想岔了”。
2. **它给的，至少改一处**：AI 的产出不原样用，至少一处实质修改，并说明为什么。
3. **每周讲一遍**：每周关掉 AI，用自己的话把最有价值的一次收获讲出来；能答上三个追问才算过。
4. **记下它错的**：AI 答错、我纠正、我没听它的——都记进 `wiki/判断记录/`。
5. **每两周关 AI 自测一次**：同难度、不用 AI、限时自己做一次，看撤了 AI 还剩多少。

> 这五条是“人那一半”。外脑可以提醒和留痕，但不替你完成。

## 第四部分：两张提示词卡

### 学习模式

```text
从现在起进入「学习模式」。当我问你问题时：
1. 先不要直接给答案。先问我“你自己的想法/思路是什么，先写一步看看”。
2. 等我给出尝试后，再给方向和线索，一次只给一步。
3. 只有我明确说“给我答案”时，才给完整答案；给之前先问我“你自己先试到哪了”。
4. 我答错时，不要直接纠正结论，先反问引导我自己发现错在哪。
```

### 干活模式

```text
进入「干活模式」：这是真实产出，请正常、高效地给我完整结果。
```

## 怎么算你成了“AI 原生新人类”？

两条就够：

1. 你能和 AI 配合，把真事做成。
2. 关掉 AI，你比以前更会想。

不是装了多少工具，也不是存了多少笔记。
