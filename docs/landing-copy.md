# 外脑 Starter Kit · 整页文案

**你用过很多 AI，但关掉它，你还剩下多少？**

外脑不是又一个第二大脑。它是一份你写给 AI 的宪法：该记的记，不该记的不记；该教你的时候，先问你。

30 分钟起步，让 AI 变成你的一部分，而不是你变成 AI 的一部分。

**〔2 分钟，测你适合哪一档〕**　**〔先看模板〕**

不用写代码 · 任何 AI 都能用 · `private/` 永不出本机

> **时间口径**：下面所有时间都分三种——**起步**（一次性）、**日常**（每天）、**周复盘**（每周额外，不是替代日常）。

---

## AI 让你更快，也可能让你更空

- **聊完就忘**：AI 很懂你，但换个对话就归零。
- **记了不用**：笔记越堆越多，真到决策时还是靠感觉。
- **越用越依赖**：AI 给的答案很顺，关掉它，你自己想不出来。

一项近千人实验提示：随手用 AI 的人，练习时成绩更高，但撤掉 AI 后反而更低；只有“只给提示、不给答案”的护栏版没有这个伤害。  
*来源：PNAS 2025，转引自《外脑起步包》。*

所以问题不是 AI 不够强，是**你没把判断长在自己身上**。

---

## 外脑不是让你记住更多，是让你自己长出更多

它不替你思考，它帮你把思考留下来。

- **该记的记**：结论、踩过的坑、可复用的模板、你说“记一下”的。
- **不该记的不记**：密码、身份信息、别人的秘密、健康家庭财务。
- **拿不准先问**：不静默写入，不替你做决定。

## 一份宪法 + 三个文件夹 + 一条日常循环

**宪法 `AGENTS.md`**  
你是谁、现在最重要的事、什么值得记、什么绝对不记、AI 该怎么提醒你。

**工作台 `进行中.md`**  
每次收尾更新：做到哪了、卡在哪、下一步是什么。

**知识库 `wiki/`**  
一事一页，结论标来源，过时能追溯。

**边界 `private/`**  
永不出本机。拿不准的先放这里，放宽永远比收紧容易。

**循环**  
对话 → 确认记忆 → 更新工作台 → 带来源召回 → 纠正 → 复盘。

---

## 30 分钟起步（初级）

- 0–5 分钟：建一个空文件夹 `my-brain`
- 5–10 分钟：填宪法里的 5 个空
- 10–15 分钟：建 `进行中.md`、`wiki/`、`private/`
- 15–20 分钟：把宪法发给你的 AI，让它读一遍
- 20–25 分钟：说一件这周真实要做的事，让它用这个库帮你做
- 25–30 分钟：让它把结论写进工作台，你确认

> 起步后：**每天 5–10 分钟**收尾；周末再花 **20–30 分钟**做一次周复盘。  
> 周复盘是额外的，不是替代日常。

## 三档：先选起步方式，不是选高低

**初级 · 30 分钟起步**
- 适合：不碰终端，想先跑起来
- 工具：任何聊天 AI（ChatGPT / Claude / Gemini / 豆包）+ 文件夹/Obsidian
- 起步：30 分钟
- 日常：每天 5–10 分钟
- 周复盘：20–30 分钟（额外）
- 你会得到：3 个文件夹 + “关于我” + 一条日常循环

**中级 · 2–4 小时（一个下午）**
- 适合：会用 AI、敢上 Claude Code
- 工具：Claude Code + 一个 vault
- 起步：2–4 小时
- 日常：每天 5–10 分钟
- 周复盘：20–30 分钟（额外）
- 你会得到：AI 能读写的 vault + 收集/知识/反思

**高级 · 1 天搭骨架**
- 适合：会终端和 git，想自动化
- 工具：Claude Code + git + 定时任务
- 起步：1 天搭骨架；之后 2–3 周按需扩展
- 日常：每天 10 分钟
- 周复盘：30 分钟（额外）
- 你会得到：完整架构 + 记忆分层 + 自检器 + 调度

**Claude 说明**  
本文里的 Claude 指 Anthropic 的 Claude / Claude Code。初级不需要 Claude Code；中级用 Claude Code（命令行工具，能直接读写你的文件夹），需要敢用终端，不要求会编程；高级再加 git 和定时任务。如果你不用 Claude Code，也可以用其他能读写文件的 Agent 工具替代，本文以 Claude Code 为例。

## 为什么它不是又一个笔记软件

- **单位不是笔记，是决策**：它围绕“你现在要做什么”，不是“你存了什么”。
- **不是聊天，是工作台**：对话只是手段，任务推进才是目的。
- **不是黑箱，是可审计**：它记了什么、为什么记、什么时候该忘，你都能看见。
- **随时调用**：不是锁在某个对话里；只要 AI 能读这个文件夹，问它就能带来源召回。
- **自我迭代**：纠错、复盘、改宪法都会更新记忆和规则；重要变更你确认，不偷偷改。
- **不锁在任何一家 AI 里**：一份文件，ChatGPT、Claude、Gemini 都能读。
- **不追求让你多用它**：它的成功标准，是关掉它你还会想。

**笔记是仓库，外脑是循环：随时能叫出来，用完能改，改完会记住。**

## 有边界的大脑

- `private/` 从第一天就存在，永不出本机。
- 学习模式：该教你的时候，AI 先问“你怎么想”，不直接甩答案。
- 干活模式：赶时间时，正常高效给结果。
- 每天一份沉淀日报：告诉你“它今天记了什么”。

**AI 不替你做判断，它帮你把判断长出来。**

## 一个真实用例

**4 场面试，14 个问题，3 个反复弱项。**

- 以前：面完靠记忆，记录散在微信和备忘录，下次还错。
- 现在：每场面试后 10 分钟，更新弱项画像；下一场前，带来源召回该练什么。
- 结果：准备时间从 40 分钟压到 10 分钟，弱项从“感觉”变成“证据”。

**不是演示，是一条真跑过的循环。**

## 常见问题

**要写代码吗？**  
不用。初级档零终端，任何聊天 AI + 一个文件夹就能开始。

**能用 ChatGPT / Claude / Gemini 吗？**  
能。外脑是一份文件，不是某个 App 的功能；初级任何聊天 AI 都行，中高级用 Claude Code。

**我的数据安全吗？**  
`private/` 永不出本机；可分享层和私有层从第一天分开。

**免费吗？**  
Starter Kit 开源；你的外脑是你自己的文件，不是租来的账号。

**不用了会怎样？**  
文件还在你手里。没有锁定，没有迁移成本。

**这不就是笔记软件吗？**  
不是。笔记软件存内容；外脑管的是“记什么、什么时候用、什么时候该忘”。
