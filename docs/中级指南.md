# 中级指南 · 2–4 小时（一个下午）

日期：2026-11-15
背景与来源：基于爱玩社区《AI 原生新人类·装机包 v1》的中级路径改写。
结论：用 Claude Code + 一个 vault，让 AI 直接读写你的文件夹；需要敢用终端，不要求会编程。

## 适合谁

- 你常用 AI，让它写过东西、处理过文件。
- 你敢打开终端，遇到报错愿意和 AI 一起排查半小时。
- 你想要一个 AI 能直接读写的 vault，而不只是聊天窗口。
- 你能拿出 2–4 小时。

## 你会得到

- 一个 AI 能读写的 vault：`my-brain/`
- 收集 / 知识 / 反思三个区域
- 宪法、工作台、`wiki/`、`private/`
- 一套权限配置：库内放行，删除/出网要问
- 一条日常循环

## 你需要

- Claude Code：Anthropic 的命令行 AI 工具（不是 Claude 聊天网页）。
- 一个终端。
- 一个文件夹。
- 不需要会编程；但需要敢看报错。

> 如果你不用 Claude Code，也可以用其他能读写文件的 Agent 工具替代。本文以 Claude Code 为例。

## 步骤

### 1. 安装 Claude Code

按 Anthropic 官方文档安装 Claude Code。安装后在终端里确认它能启动。

### 2. 建 vault

- 新建空文件夹 `my-brain`。
- `git init`（可选，但推荐；这样每次改动可追溯）。
- 复制仓库根目录的 `AGENTS.md`、`进行中.md`。
- 建 `wiki/`、`private/`。
- `.gitignore` 写入 `private/*` 和 `!private/.gitkeep`。

### 3. 配权限

- 复制 `templates/settings.json` 到 `my-brain/.claude/settings.json`。
- 先手动跑一次，验证：
  1. 让 AI 在库里建 `test.md` → 应该不弹确认。
  2. 让 AI 删 `test.md` → 应该弹确认。
- 两个都对，权限才算配好。详见 [权限配置](权限配置.md)。

### 4. 让 AI 读宪法

- 在 `my-brain/` 里启动 Claude Code。
- 说：“读 `AGENTS.md`，之后按它来。”
- 让它复述：你是谁、现在最重要的事、什么绝对不记、拿不准怎么办。
- 如果它复述错了，改宪法，不要改它的记忆。

### 5. 做一件真事

- 说一件你这周真实要做的事。
- 让它先读 `wiki/` 和 `进行中.md`，再动手。
- 过程里观察三件事：
  1. 它有没有带来源引用旧内容？
  2. 它有没有在拿不准时问你？
  3. 它有没有把结论写进工作台？

### 6. 配学习模式

- 把 `templates/学习模式.md` 里的提示词发给它。
- 验证：问一个你会的问题，它应该先反问你“你怎么想”，而不是直接给答案。
- 如果它直接给答案，重贴提示词。

## 日常怎么用

- 每天 5–10 分钟：推进一个真实任务，更新工作台。
- 每周 20–30 分钟：周复盘，改一条规则。
- 每次它写文件前，你至少看一眼路径；写 `private/` 一律拒绝。

## 验收：四个信号

1. 它能直接读写 vault，不需要你复制粘贴。
2. 它引用旧内容时带来源。
3. 它删文件/出网时会问你。
4. 它会在学习模式里先反问你。

## 常见错误

- **没配权限就自动化**：每一步都弹确认，任务其实没跑成。
- **把 `private/` 也放行**：隐私层形同虚设。
- **装太多插件**：先跑通一条循环，再加工具。
- **让 AI 替你填宪法**：规则必须你自己答。
- **不验证删除确认**：只过“建文件”不过“删文件”，等于把门拆了。
